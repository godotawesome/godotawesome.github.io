GodotAwesome is an independent guide for people making games with the **Godot Engine**. We publish practical tutorials, quick code answers, plugin and tool write-ups, release explainers and stories about games built with Godot.

## Who is behind it

GodotAwesome is run by **Alihan**, a solo developer, and published by MgonnacrushT Limited. Articles appear under the **GodotAwesome Team** byline or under the name of the author who wrote them.

## How we write

Articles are prepared with the help of AI tools, checked against official sources (the Godot docs, release notes and project repositories) and reviewed before they go live. Every article shows when it was last updated. You can read the details on the [How we work](/how-we-work/) page.

## What you will find here

- Practical guides for Godot 4
- Quick code answers you can copy and paste
- Plugin and tool write-ups with install links
- Release explainers and upgrade notes
- Stories about games made with Godot

## Write for us

GodotAwesome is open source. If you want to fix a mistake or write a guest article, the instructions are in the [contributing guide](https://github.com/godotawesome/godotawesome.github.io/blob/main/CONTRIBUTING.md).
